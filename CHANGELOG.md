# Изменения форка

## 2026-09-15 — Claude и Codex

- `claude-desktop` из репозитория omarchy; для Cowork доставлены `qemu-system-x86`,
  `edk2-ovmf`, `virtiofsd` (explicit, чтобы не удалялись как сироты), пользователь в группе `kvm`.
- `chatgpt-desktop` из AUR (официальный .deb OpenAI, включает Codex).
- CLI через mise: Claude Code 2.1.273, Codex 0.154.0; `config/mise/config.toml` в репо
  и в `yoga-recovery`.
- `config/packages.txt` разделён на пакеты из репозиториев и AUR.

## 2026-09-15 — Vivaldi

- Установлены `vivaldi` и `vivaldi-ffmpeg-codecs` из extra; список пакетов в `config/packages.txt`.
- `~/.config/vivaldi-stable.conf`: нативный Wayland, gnome-libsecret, жест «назад» тачпадом.
  Ставится установщиком и сохраняется `yoga-recovery`.
- Vivaldi — браузер по умолчанию (`xdg-settings`, http/https/html/about/unknown);
  `mimeapps.list` сохранён в `config/` и в `yoga-recovery`. Веб-приложения Omarchy
  (`omarchy launch webapp`) по-прежнему открываются в Chromium.

## 2026-09-15 — своп, сон и резервная копия бара

- SWAP.md: текущая схема zram 15.3 ГБ + swapfile 15.3 ГБ, почему не 32 ГБ.
- Закрытие крышки: suspend-then-hibernate через 2 ч на батарее, от сети — обычный сон.
  `bin/yoga-sleep-setup` проверяет resume_offset перед установкой.
- В репозиторий добавлены плагины `gon7187.monitor`, `gon7187.power` и `shell.json`;
  установщик ставит все плагины из `config/omarchy/plugins`.
- Бэкап установщика хранит файлы по относительному пути, одноимённые не затираются.
- `yoga-recovery` сохраняет конфиги сна из `/etc` как справочные копии.

## 2026-09-15 — CPU и RAM в баре

- Новый плагин бара `gon7187.sysstats`: `CPU N%  RAM N%` (свободная память по
  MemAvailable), читает `/proc` без запуска процессов, клик открывает btop.
- Установщик ставит плагин и добавляет его в центр бара после погоды.
- `yoga-recovery` сохраняет `shell.json` и пользовательские плагины бара.

## 2026-09-15 — сохранённый профиль Yoga Panel

- Открытие панели тапом 8–10 пальцами по нижнему экрану, с допуском на неодновременный отрыв.

- Свайпы переключают верхний экран по 1, 3…10; нижний workspace 2 пропускается.
- Профиль владельца включён в defaults.json и согласован с интерфейсом и сбросом.
- RU/EN переключается по тапу; скольжение не считается нажатием.
- Системная раскладка определяется по активной клавиатуре.
- Исправлен откат: тип плавной прокрутки передаётся после каждой оси Wayland.
- Инерция синхронизирована с кадрами, зависит от скорости свайпа и усиливается
  при повторных свайпах в ту же сторону; короткие задержки не обрывают её.
- Esc расположен перед Ё; RU/EN и микрофон находятся в нижнем ряду.
- Доступны RU/EN словари, автоисправление с отменой через Backspace,
  голосовой ввод Parakeet, синхронизация яркости и восстановление после обновлений.

Проверки включают жесты, раскладку, Qt-касания, голосовые команды с заглушками,
восстановление в отдельном временном HOME и настоящий Wayland-приёмник прокрутки.
Интерактивные тесты ввода запускаются отдельно и явно.
